FORGEFALL

Voxel MW2-style FPS for Android, Linux / Steam Deck, and Windows. Portals, grapple, wall-running, and an AI Forge that builds the map as you play.

INSTALL — ANDROID

  1. Tap Download above.
  2. Open the downloaded file. If your phone asks, allow Install unknown apps for your browser — it only applies to this install.
  3. Tap Install, then Open.
  4. Updates arrive automatically inside the game.

INSTALL — LINUX / STEAM DECK

  1. Download the Linux zip and unzip it anywhere.
  2. Run chmod +x forgefall.x86_64, then ./forgefall.x86_64 (keep forgefall.pck in the same folder).
  3. On Deck: add it in Desktop Mode via Steam > Games > Add a Non-Steam Game, then launch from Game Mode. Native gamepad support — leave Steam's controller layout on the default "Gamepad" template.

INSTALL — WINDOWS

  1. Download the Windows zip and unzip it anywhere.
  2. Double-click forgefall.exe (keep forgefall.pck in the same folder — the game won't start without it).
  3. In gameplay the mouse is captured to steer the camera; in menus it is visible and free. Press Esc to pause and release the mouse.
